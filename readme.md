# AWS Terraform Infrastructure Lab

## Overview

This project demonstrates Infrastructure as Code (IaC) using Terraform to automate the deployment and management of AWS cloud resources. The lab focuses on building core AWS infrastructure components, implementing networking, compute, storage, security, and identity management services through code.

## Technologies Used

- Terraform
- Amazon Web Services (AWS)
- Amazon EC2
- Amazon VPC
- Amazon S3
- AWS IAM
- Security Groups
- Git
- GitHub

## Resources Provisioned

### Networking
- Virtual Private Cloud (VPC)
- Public Subnet
- Private Subnet
- Internet Gateway
- Route Table

### Compute
- Public EC2 Instance
- Private EC2 Instance

### Storage
- S3 Bucket
- S3 Object

### Security & Identity
- Security Group
- IAM User
- IAM Role
- IAM Policies

## Project Architecture

AWS Cloud
├── VPC
│ ├── Public Subnet
│ │ └── EC2 Instance
│ ├── Private Subnet
│ │ └── EC2 Instance
│ ├── Internet Gateway
│ └── Route Table
├── S3 Bucket
├── Security Group
└── IAM
├── User
├── Role
└── Policies

## Terraform Workflow

```bash
terraform init
terraform plan
terraform apply
terraform destroy
```

## Skills Demonstrated

- Infrastructure as Code (IaC)
- AWS Resource Provisioning
- Cloud Networking
- Identity and Access Management (IAM)
- Security Group Configuration
- Terraform State Management
- Cloud Automation
- Git Version Control
- GitHub Project Documentation

## Key Learning Outcomes

- Automated AWS infrastructure deployment using Terraform
- Built a secure network architecture with public and private subnets
- Configured IAM users, roles, and policies
- Deployed and managed EC2 compute resources
- Provisioned and managed S3 storage resources
- Implemented security controls through Security Groups
- Managed infrastructure through a repeatable and scalable IaC workflow
