# Terraform AWS VPC Lab

## Overview
This project uses Terraform to deploy an AWS VPC using Infrastructure as Code.

## Resources
- AWS VPC
- CIDR Block: 10.0.0.0/16
- Region: us-east-1

## Commands

terraform init

terraform plan

terraform apply

terraform destroy
